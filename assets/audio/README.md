# Custom Audio Assets (Optional)

`AudioManager` automatically synthesizes all hardware and OS sounds using 16-bit PCM procedural synthesis out-of-the-box.

To override any built-in sound with custom recordings, drop `.ogg` files into these paths:
- `res://assets/audio/ambient/fan_hum.ogg` — Seamless workstation cooling fan loop
- `res://assets/audio/sfx/hdd_click.ogg` — Single hard disk head click
- `res://assets/audio/sfx/hdd_burst.ogg` — Multi-seek hard disk chatter
- `res://assets/audio/sfx/floppy_seek.ogg` — 3.5" floppy drive stepper seek
- `res://assets/audio/sfx/disk2_bang.ogg` — 5.25" Apple Disk II track-00 clatter
- `res://assets/audio/sfx/optical_seek.ogg` — CD-ROM laser lens focus and sled homing seek
- `res://assets/audio/sfx/post_beep.ogg` — BIOS POST speaker beep
